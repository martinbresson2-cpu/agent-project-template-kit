## Update rule

Update this file when:
- a meaningful capability is added or removed from intended scope
- a major exclusion changes
- assumptions behind the product boundary change

Do not use this file for implementation progress.
Active work belongs in `docs/roadmap/current_feature.md`.
Milestones belong in `docs/roadmap/next_phase.md`.
