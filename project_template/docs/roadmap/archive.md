# Archive — Completed Work

> Record shipped or explicitly completed milestones only.
> Keep this short.
> Delete this file during bootstrap if the project is too small to need a completion log.

---

## Purpose

Use this file to keep a lean record of completed work after it leaves:
- `docs/roadmap/current_feature.md`
- `docs/roadmap/next_phase.md`

This is not a diary.
This is not a backlog.
This is not a bug history.

---

## What belongs here

- completed milestones
- completed feature slices worth remembering
- notable shipped changes
- major bootstrap completion markers

Keep entries brief and outcome-focused.

## Move-to-archive rule

Move work here when:
- it is finished,
- the current state is no longer active,
- and the user has signed off if signoff is required.

Then remove or simplify the old active planning text so roadmap files stay current.

## Keep it lean

Do not copy full task lists here.
Do not duplicate design decisions.
Do not paste verification logs.
Link to canonical files if more detail still matters.
